# oneuptime_form_domain (Resource)

Your own domains a form answers on, such as report.acmeinc.com, verified and served over HTTPS.

## Example Usage

```terraform
resource "oneuptime_form_domain" "example" {
  domain_id = oneuptime_domain.example.id
  form_id   = oneuptime_form.example.id
}
```

## Schema

### Required

- `domain_id` (String) ID of the verified domain this one is a subdomain of. The domain must be verified in Project Settings > Advanced > Domains. The ID of a `oneuptime_domain`.
- `form_id` (String) ID of the form this domain answers with. Fixed once the domain is added: to put the domain on another form, delete it and add it there. The ID of a `oneuptime_form`.

### Optional

- `custom_certificate` (String) The certificate, in PEM format, to serve the domain with instead of the free one. Used while isCustomCertificate is on.
- `custom_certificate_key` (String) The custom certificate's private key, in PEM format. Used while isCustomCertificate is on.
- `is_custom_certificate` (Boolean) Serve the domain with the certificate you upload rather than the free SSL certificate OneUptime issues and renews. Defaults to `false`.
- `subdomain` (String) Subdomain label for your form such as 'report'. Leave blank or enter @ to use the root domain.

### Read-Only

- `certificate_reissue_requested_at` (String) When a reissue of the SSL certificate for this domain was last requested. Used to rate limit how often a certificate can be reissued.
- `created_at` (String) Date and Time when the object was created.
- `created_by_user_id` (String) User ID who created this object (if this object was created by a User). The ID of a `oneuptime_user` (see the data source).
- `full_domain` (String) Full domain of your form (like report.acmeinc.com). This is autogenerated and is derived from subdomain and domain.
- `id` (String) Unique identifier for the resource.
- `is_cname_verified` (Boolean) Whether the domain's CNAME record has been found pointing to this installation. Checked every 15 minutes, or on Check now.
- `is_ssl_ordered` (Boolean) Whether a free SSL certificate has been ordered for the domain. Ordered on its own once the CNAME record is verified.
- `is_ssl_provisioned` (Boolean) Whether the domain serves its free SSL certificate yet.
- `project_id` (String) ID of your OneUptime Project in which this object belongs. The ID of a `oneuptime_project`.
- `updated_at` (String) Date and Time when the object was updated.

## Import

Import an existing form domain by its id, with an `import` block (Terraform 1.5+, OpenTofu 1.6+):

```terraform
import {
  to = oneuptime_form_domain.example
  id = "<id>"
}
```

or on the command line:

```shell
terraform import oneuptime_form_domain.example <id>
```
