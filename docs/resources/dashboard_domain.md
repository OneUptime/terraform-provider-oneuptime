# oneuptime_dashboard_domain (Resource)

Manage custom domains for your dashboard

## Example Usage

```terraform
resource "oneuptime_dashboard_domain" "example" {
  domain_id = "123e4567-e89b-12d3-a456-426614174000"
  dashboard_id = "123e4567-e89b-12d3-a456-426614174000"
}
```

## Schema

### Required

- `domain_id` (String) A unique identifier for an object, represented as a UUID..
- `dashboard_id` (String) A unique identifier for an object, represented as a UUID..

### Optional

- `project_id` (String) A unique identifier for an object, represented as a UUID..
- `subdomain` (String) Subdomain label for your dashboard such as 'dashboard'. Leave blank or enter @ to use the root domain...
- `created_by_user_id` (String) A unique identifier for an object, represented as a UUID..
- `custom_certificate` (String) Dashboard domain custom_certificate.
- `custom_certificate_key` (String) Dashboard domain custom_certificate_key.
- `is_custom_certificate` (Bool) Dashboard domain is_custom_certificate.

### Read-Only

- `id` (String) Unique identifier for the resource.
- `created_at` (String) A date time object..
- `updated_at` (String) A date time object..
- `deleted_at` (String) A date time object..
- `version` (Number) Object version.
- `full_domain` (String) Full domain of your dashboard (like dashboard.acmeinc.com). This is autogenerated and is derived from subdomain and domain...
- `is_cname_verified` (Bool) Is CNAME Verified?..
- `is_ssl_ordered` (Bool) Is SSL ordered?..
- `is_ssl_provisioned` (Bool) Is SSL provisioned?..

## Import

Import is supported using the following syntax:

```shell
terraform import oneuptime_dashboard_domain.example <id>
```
