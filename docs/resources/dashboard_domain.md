# oneuptime_dashboard_domain (Resource)

Manage custom domains for your dashboard

## Example Usage

```terraform
resource "oneuptime_dashboard_domain" "example" {
  domain_id    = oneuptime_domain.example.id
  dashboard_id = oneuptime_dashboard.example.id
}
```

## Schema

### Required

- `dashboard_id` (String) ID of your Dashboard resource where this object belongs. The ID of a `oneuptime_dashboard`.
- `domain_id` (String) The ID of a `oneuptime_domain`.

### Optional

- `custom_certificate` (String)
- `custom_certificate_key` (String)
- `is_custom_certificate` (Boolean)
- `subdomain` (String) Subdomain label for your dashboard such as 'dashboard'. Leave blank or enter @ to use the root domain.

### Read-Only

- `certificate_reissue_requested_at` (String) When a reissue of the SSL certificate for this domain was last requested. Used to rate limit how often a certificate can be reissued.
- `created_at` (String) Date and Time when the object was created.
- `created_by_user_id` (String) User ID who created this object (if this object was created by a User). The ID of a `oneuptime_user` (see the data source).
- `full_domain` (String) Full domain of your dashboard (like dashboard.acmeinc.com). This is autogenerated and is derived from subdomain and domain.
- `id` (String) Unique identifier for the resource.
- `is_cname_verified` (Boolean) Is CNAME Verified?
- `is_ssl_ordered` (Boolean) Is SSL ordered?
- `is_ssl_provisioned` (Boolean) Is SSL provisioned?
- `project_id` (String) ID of your OneUptime Project in which this object belongs. The ID of a `oneuptime_project`.
- `updated_at` (String) Date and Time when the object was updated.

## Import

Import an existing dashboard domain by its id, with an `import` block (Terraform 1.5+, OpenTofu 1.6+):

```terraform
import {
  to = oneuptime_dashboard_domain.example
  id = "<id>"
}
```

or on the command line:

```shell
terraform import oneuptime_dashboard_domain.example <id>
```
