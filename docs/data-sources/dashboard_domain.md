# oneuptime_dashboard_domain (Data Source)

Manage custom domains for your dashboard

Look one up by `id`, or by any of its other arguments: every argument you set must match, and exactly one dashboard domain may match them all - none, or more than one, is an error rather than an empty or arbitrary result.

## Example Usage

```terraform
data "oneuptime_dashboard_domain" "example" {
  domain_id = oneuptime_domain.example.id
}

# Or by id:
data "oneuptime_dashboard_domain" "by_id" {
  id = "<id>"
}
```

## Schema

### Optional

- `created_by_user_id` (String) User ID who created this object (if this object was created by a User). The ID of a `oneuptime_user` (see the data source).
- `custom_certificate` (String) Permissions - Create: [Project Owner, Project Admin, Project Member, Settings Admin, Settings Member, Create Dashboard Domain], Read: [Project Owner, Project Admin, Project Member, Viewer, Settings Admin, Settings Member, Settings Viewer, Read Dashboard Domain], Update: [Project Owner, Project Admin, Project Member, Settings Admin, Settings Member, Edit Dashboard Domain]
- `custom_certificate_key` (String) Permissions - Create: [Project Owner, Project Admin, Project Member, Settings Admin, Settings Member, Create Dashboard Domain], Read: [Project Owner, Project Admin, Project Member, Viewer, Settings Admin, Settings Member, Settings Viewer, Read Dashboard Domain], Update: [Project Owner, Project Admin, Project Member, Settings Admin, Settings Member, Edit Dashboard Domain]
- `dashboard_id` (String) ID of your Dashboard resource where this object belongs. The ID of a `oneuptime_dashboard`.
- `domain_id` (String) Permissions - Create: [Project Owner, Project Admin, Project Member, Settings Admin, Settings Member, Create Dashboard Domain], Read: [Project Owner, Project Admin, Project Member, Viewer, Settings Admin, Settings Member, Settings Viewer, Read Dashboard Domain], Update: [No access - you don't have permission for this operation] The ID of a `oneuptime_domain`.
- `full_domain` (String) Full domain of your dashboard (like dashboard.acmeinc.com). This is autogenerated and is derived from subdomain and domain.
- `id` (String) Look up by unique identifier. Leave unset to look up by the other arguments instead.
- `is_cname_verified` (Boolean) Is CNAME Verified?
- `is_custom_certificate` (Boolean) Permissions - Create: [Project Owner, Project Admin, Project Member, Settings Admin, Settings Member, Create Dashboard Domain], Read: [Project Owner, Project Admin, Project Member, Viewer, Settings Admin, Settings Member, Settings Viewer, Read Dashboard Domain], Update: [Project Owner, Project Admin, Project Member, Settings Admin, Settings Member, Edit Dashboard Domain]
- `is_ssl_ordered` (Boolean) Is SSL ordered?
- `is_ssl_provisioned` (Boolean) Is SSL provisioned?
- `subdomain` (String) Subdomain label for your dashboard such as 'dashboard'. Leave blank or enter @ to use the root domain.

### Read-Only

- `certificate_reissue_requested_at` (String) When a reissue of the SSL certificate for this domain was last requested. Used to rate limit how often a certificate can be reissued.
- `created_at` (String) Date and Time when the object was created.
- `project_id` (String) ID of your OneUptime Project in which this object belongs. The ID of a `oneuptime_project`.
- `updated_at` (String) Date and Time when the object was updated.
