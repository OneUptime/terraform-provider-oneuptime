# oneuptime_status_page_domain (Data Source)

Manage custom domains for your status page

Look one up by `id`, or by any of its other arguments: every argument you set must match, and exactly one status page domain may match them all - none, or more than one, is an error rather than an empty or arbitrary result.

## Example Usage

```terraform
data "oneuptime_status_page_domain" "example" {
  created_by_actor_type = "User"
}

# Or by id:
data "oneuptime_status_page_domain" "by_id" {
  id = "<id>"
}
```

## Schema

### Optional

- `created_by_actor_id` (String) ID of the API key, workflow or MCP client authorization that created this object. Empty when a person or OneUptime itself created it.
- `created_by_actor_type` (String) What created this object: User, ApiKey, Workflow, McpClient (for a person), MasterAdmin or System (OneUptime). Empty if made before it was recorded.
- `created_by_user_id` (String) User ID who created this object (if this object was created by a User). The ID of a `oneuptime_user` (see the data source).
- `custom_certificate` (String) Your certificate for the domain, in PEM, with its chain. Used when Is Custom Certificate is on.
- `domain_id` (String) Permissions - Create: [Project Owner, Project Admin, Project Member, Status Page Admin, Status Page Member, Create Status Page Domain], Read: [Project Owner, Project Admin, Project Member, Viewer, Status Page Admin, Status Page Member, Status Page Viewer, Read Status Page Domain], Update: [No access - you don't have permission for this operation] The ID of a `oneuptime_domain`.
- `full_domain` (String) Full domain of your status page (like status.acmeinc.com). This is autogenerated and is derived from subdomain and domain.
- `id` (String) Look up by unique identifier. Leave unset to look up by the other arguments instead.
- `is_cname_verified` (Boolean) Is CNAME Verified?
- `is_custom_certificate` (Boolean) When on, the domain is served with your own certificate (custom_certificate and its key) instead of one OneUptime gets from Let's Encrypt.
- `is_ssl_ordered` (Boolean) Is SSL ordered?
- `is_ssl_provisioned` (Boolean) Is SSL provisioned?
- `last_modified_by_actor_id` (String) ID of the API key, workflow or MCP client authorization that last changed this object. Empty when a person last changed it.
- `last_modified_by_actor_type` (String) What last changed this object: User, ApiKey, Workflow, McpClient (for a person) or MasterAdmin. Empty until it is changed after it is created.
- `last_modified_by_user_id` (String) ID of the person who last changed this object, or the member an MCP client changed it for. Empty when an API key or a workflow last changed it. The ID of a `oneuptime_user` (see the data source).
- `status_page_id` (String) ID of your Status Page resource where this object belongs. The ID of a `oneuptime_status_page`.
- `subdomain` (String) Subdomain label for your status page such as 'status'. Leave blank or enter @ to use the root domain.

### Read-Only

- `certificate_reissue_requested_at` (String) When a reissue of the SSL certificate for this domain was last requested. Used to rate limit how often a certificate can be reissued.
- `created_at` (String) Date and Time when the object was created.
- `last_modified_at` (String) When a person, an API key, a workflow or an MCP client last changed this object. OneUptime's own updates do not count. Empty until it is changed.
- `project_id` (String) ID of your OneUptime Project in which this object belongs. The ID of a `oneuptime_project`.
- `updated_at` (String) Date and Time when the object was updated.
