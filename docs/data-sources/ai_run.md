# oneuptime_ai_run (Data Source)

One AI agent execution: LLM calls, tool calls, cost, and the egress manifest of what was sent to the LLM.

Look one up by `id`, or by any of its other arguments: every argument you set must match, and exactly one ai run may match them all - none, or more than one, is an error rather than an empty or arbitrary result.

## Example Usage

```terraform
data "oneuptime_ai_run" "example" {
  run_type = "example-run-type"
}

# Or by id:
data "oneuptime_ai_run" "by_id" {
  id = "<id>"
}
```

## Schema

### Optional

- `ai_agent_id` (String) The external AI agent that claimed this run (for code-fix runs executed by an agent container).
- `analysis_tldr` (String) For investigation runs: a one or two sentence plain-text summary of the posted analysis, generated by AI.
- `attempt_count` (Number) How many times a worker has claimed this run for execution. Incremented on each claim; the queue stops retrying after the maximum.
- `auto_grade` (String) For investigation runs: how the posted analysis compared to the incident's final recorded root cause (Match, Partial or Mismatch).
- `code_fix_recommendation` (String) For incident/alert investigations: whether the structured investigation outcome recommends opening a code-fix pull request.
- `code_fix_task_type` (String) For CodeFix runs: which task recipe this run executes (fix the exception, write a regression test, ...). Null means FixException — rows created before task recipes existed.
- `conversation_id` (String) ID of the conversation this run belongs to. The ID of a `oneuptime_ai_conversation`.
- `error_message` (String) Error message if the run failed.
- `human_verdict` (String) For investigation runs: the one-click human verdict on the posted analysis (Confirmed or Rejected). Null until a user weighs in.
- `human_verdict_by_user_id` (String) The user who recorded (or last changed) the human verdict.
- `id` (String) Look up by unique identifier. Leave unset to look up by the other arguments instead.
- `llm_call_count` (Number) Number of LLM calls made during this run.
- `monitor_id` (String) The monitor behind the alert that triggered this run — the dedupe key for per-monitor investigation windows.
- `run_type` (String) Type of AI run: Chat or Investigation.
- `status` (String) Current status of this run.
- `task_number` (Number) Per-project sequential number for this AI task (code-fix runs only).
- `tool_call_count` (Number) Number of tool calls executed during this run.
- `total_cost_in_usd_cents` (Number) Total billed cost of this run in USD cents.
- `total_tokens` (Number) Total LLM tokens used during this run.
- `triggered_by_ai_insight_id` (String) The preventive AI insight that triggered this run (for insight triage and insight-created fix runs).
- `triggered_by_alert_id` (String) The alert that triggered this run (for autonomous investigations).
- `triggered_by_auto_remediation_suggestion_id` (String) The auto-remediation suggestion this planning run picks a runbook for.
- `triggered_by_incident_id` (String) The incident that triggered this run (for autonomous investigations).
- `triggered_by_telemetry_exception_id` (String) The telemetry exception that triggered this run (for code-fix runs).
- `user_id` (String) ID of the user who triggered this run. The ID of a `oneuptime_user` (see the data source).

### Read-Only

- `auto_grade_at` (String) When the automatic grade was recorded.
- `completed_at` (String) When the run completed.
- `created_at` (String) Date and Time when the object was created.
- `egress_manifest` (String) What data was sent to which LLM during this run: provider, model, and per-tool row/byte/redaction counts. A JSON value: write it with `jsonencode()`.
- `human_verdict_at` (String) When the human verdict was recorded (or last changed).
- `last_heartbeat_at` (String) Last time the run reported progress. Used to detect and fail stale runs.
- `project_id` (String) ID of the project this run belongs to. The ID of a `oneuptime_project`.
- `started_at` (String) When the run started.
- `updated_at` (String) Date and Time when the object was updated.
