# oneuptime_llm_log (Data Source)

Logs of all the LLM API calls for AI features in this project. Look up by `id` or by `name` (must match exactly one item).

## Example Usage

Look up by `name` (must match exactly one item) or by `id`:

```terraform
data "oneuptime_llm_log" "by_name" {
  name = "example-llm_log"
}

data "oneuptime_llm_log" "by_id" {
  id = "123e4567-e89b-12d3-a456-426614174000"
}
```

## Schema

- `id` (String) Look up by unique identifier. Exactly one of `id` or `name` must be set.. Computed.
- `name` (String) Look up by name. Exactly one of `id` or `name` must be set. Fails if the name does not match exactly one item.. Computed.
- `created_at` (String) A date time object.. Computed.
- `updated_at` (String) A date time object.. Computed.
- `deleted_at` (String) A date time object.. Computed.
- `version` (Number) Object version. Computed.
- `project_id` (String) A unique identifier for an object, represented as a UUID.. Computed.
- `llm_provider_id` (String) A unique identifier for an object, represented as a UUID.. Computed.
- `llm_provider_name` (String) Name of the LLM Provider at time of call.. Computed.
- `llm_type` (String) Type of LLM (OpenAI, Azure OpenAI, Anthropic, Groq, Mistral, Ollama).. Computed.
- `model_name` (String) Name of the model used (e.g., gpt-4, claude-3-opus).. Computed.
- `is_global_provider` (Bool) Was a global LLM provider used for this call?.. Computed.
- `total_tokens` (Number) Total tokens used (input + output).. Computed.
- `completion_tokens` (Number) Output (completion) tokens generated by this call.. Computed.
- `cached_input_tokens` (Number) Input tokens served from the provider's prompt cache (billed at a discount).. Computed.
- `cache_creation_tokens` (Number) Input tokens written to the provider's prompt cache on this call.. Computed.
- `cost_in_usd_cents` (Number) Total cost in USD cents.. Computed.
- `was_billed` (Bool) Was the project charged for this API call?.. Computed.
- `status` (String) Status of the LLM API call.. Computed.
- `status_message` (String) Status Message (error details if failed).. Computed.
- `feature` (String) The feature that triggered this API call (e.g., IncidentPostmortem).. Computed.
- `request_prompt` (String) The prompt sent to the LLM (truncated).. Computed.
- `response_preview` (String) Preview of the LLM response (truncated).. Computed.
- `incident_id` (String) A unique identifier for an object, represented as a UUID.. Computed.
- `alert_id` (String) A unique identifier for an object, represented as a UUID.. Computed.
- `ai_run_id` (String) A unique identifier for an object, represented as a UUID.. Computed.
- `scheduled_maintenance_id` (String) A unique identifier for an object, represented as a UUID.. Computed.
- `user_id` (String) A unique identifier for an object, represented as a UUID.. Computed.
- `request_started_at` (String) A date time object.. Computed.
- `request_completed_at` (String) A date time object.. Computed.
- `duration_ms` (Number) Request duration in milliseconds.. Computed.
