# oneuptime_llm_log (Data Source)

Logs of all the LLM API calls for AI features in this project.

Look one up by `id`, or by any of its other arguments: every argument you set must match, and exactly one llm log may match them all - none, or more than one, is an error rather than an empty or arbitrary result.

## Example Usage

```terraform
data "oneuptime_llm_log" "example" {
  llm_provider_id = oneuptime_llm_provider.example.id
}

# Or by id:
data "oneuptime_llm_log" "by_id" {
  id = "<id>"
}
```

## Schema

### Optional

- `ai_run_id` (String) ID of the AI run this LLM call was part of (if any).
- `alert_id` (String) ID of Alert associated with this LLM call (if any). The ID of a `oneuptime_alert`.
- `cache_creation_tokens` (Number) Input tokens written to the provider's prompt cache on this call.
- `cached_input_tokens` (Number) Input tokens served from the provider's prompt cache (billed at a discount).
- `completion_tokens` (Number) Output (completion) tokens generated by this call.
- `cost_in_usd_cents` (Number) Total cost in USD cents.
- `duration_ms` (Number) Request duration in milliseconds.
- `feature` (String) The feature that triggered this API call (e.g., IncidentPostmortem).
- `id` (String) Look up by unique identifier. Leave unset to look up by the other arguments instead.
- `incident_id` (String) ID of Incident associated with this LLM call (if any). The ID of a `oneuptime_incident`.
- `is_global_provider` (Boolean) Was a global LLM provider used for this call?
- `llm_provider_id` (String) ID of LLM Provider used for this API call. The ID of a `oneuptime_llm_provider`.
- `llm_provider_name` (String) Name of the LLM Provider at time of call.
- `llm_type` (String) Type of LLM (OpenAI, Azure OpenAI, Anthropic, Groq, Mistral, Ollama).
- `model_name` (String) Name of the model used (e.g., gpt-4, claude-3-opus).
- `request_prompt` (String) The prompt sent to the LLM (truncated).
- `response_preview` (String) Preview of the LLM response (truncated).
- `scheduled_maintenance_id` (String) ID of Scheduled Maintenance associated with this LLM call (if any). The ID of a `oneuptime_scheduled_maintenance_event`.
- `status` (String) Status of the LLM API call.
- `status_message` (String) Status Message (error details if failed).
- `total_tokens` (Number) Total tokens used (input + output).
- `user_id` (String) ID of User who triggered this LLM call (if any). The ID of a `oneuptime_user` (see the data source).
- `was_billed` (Boolean) Was the project charged for this API call?

### Read-Only

- `created_at` (String) Date and Time when the object was created.
- `project_id` (String) ID of your OneUptime Project in which this object belongs. The ID of a `oneuptime_project`.
- `request_completed_at` (String) When the LLM request completed.
- `request_started_at` (String) When the LLM request started.
- `updated_at` (String) Date and Time when the object was updated.
